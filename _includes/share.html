{% comment %} Uso: {% include share.html post=post %} Botones para compartir la entrada en LinkedIn, X, WhatsApp y por correo. Son enlaces directos a la URL de "compartir"/"intent" de cada red — sin JS de terceros, sin widget externo ni cookies de tracking (mismo criterio que el resto del tema: buscador, comentarios y demás plugins de WordPress sin equivalente sencillo tampoco se migraron, ver CLAUDE.md). El título se escapa con el filtro `cgi_escape`, no `uri_escape`: este último no escapa `&`, `=` ni `?` (son válidos dentro de una query), así que un título que los contenga (p. ej. "CI/CD: ¿qué es?") rompería el resto de parámetros del enlace. Para el enlace de correo se sustituye además el `+` que genera `cgi_escape` para los espacios por `%20`: el esquema mailto no es una query string de formulario, y varios clientes de correo muestran el `+` literal en vez de interpretarlo como espacio. Los iconos son SVG en línea (el trazo de cada marca, sin fuente de iconos externa) — mismo criterio que el icono de hamburguesa del menú responsive, para no depender de dashicons. El botón "Compartir con..." usa la Web Share API nativa del navegador (assets/js/share.js) y está oculto (`hidden`) hasta que ese script confirma que el navegador la soporta — normalmente móvil. Sin JS, o sin soporte, el resto de enlaces siguen funcionando igual. {% endcomment %} {% assign url_entrada = site.url | append: include.post.url %} {% assign titulo_entrada = include.post.title | strip_html %} {% assign url_codificada = url_entrada | cgi_escape %} {% assign titulo_codificado = titulo_entrada | cgi_escape %} {% assign titulo_correo = titulo_codificado | replace: '+', '%20' %} {% assign url_correo = url_codificada | replace: '+', '%20' %}
